# Student Grade Calculator

## Task
Create a Python program that calculates grades for students based on their marks using predefined grading conditions.

## Objective
Practice conditional statements and apply them to a simple data-analysis problem.

## Tools
- Python
- Jupyter Notebook

## Grading Logic

| Marks | Grade |
|---|---|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |
| Below 0 or above 100 | Invalid marks |

## How the program works

The program validates marks and then uses if, elif, and else statements to assign the appropriate grade.

## Test Cases

- 95 → A
- 86 → B
- 74 → C
- 63 → D
- 48 → F
- -5 → Invalid marks
- 105 → Invalid marks
